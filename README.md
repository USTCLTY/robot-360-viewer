# 机器人 360° 展示

一个基于 Web 的机器人 360° 全景交互展示页面。

## 在线预览

> 部署后在此填入 GitHub Pages 链接

## 项目结构

```
.
├── Open.html          # 入口页面（自动跳转）
├── Data/
│   ├── index.html     # 主展示页
│   ├── css/
│   ├── js/            # 交互逻辑（360° 旋转、缩放等）
│   ├── images/        # 360° 序列帧图片
│   └── assets/        # 图标等资源
└── thumbnail.png      # 项目缩略图
```

## 功能特性

- 360° 鼠标/触摸拖拽旋转
- 滚轮缩放
- 全屏查看模式
- 响应式布局

## 技术栈

- HTML5 / CSS3 / JavaScript
- 自定义 360° 渲染引擎

## 本地运行

直接在浏览器中打开 `Open.html` 即可。
